# Kubernetes Learning Repository

## Overview

This repository contains my hands-on learning and practice while exploring Kubernetes. It includes deployments, services, configuration files, and real-world examples that helped me understand how applications are deployed, managed, and scaled in a Kubernetes cluster.

The exercises in this repository are based on official Kubernetes documentation, online learning resources, and practical labs. I used them to strengthen my understanding by deploying and troubleshooting the workloads in my own environment.
